# parameters

## Functions

- [add_custom](add_custom.md) — Add a custom parameter row with an empty value of the chosen kind.
- [commit_measurement](commit_measurement.md) — Commit a measurement parameter (value + unit) from its edit buffer,
- [commit_number](commit_number.md) — Commit a numeric parameter from its edit buffer, ignoring a buffer
- [remove](remove.md) — Drop a parameter from the row.
- [set_bool](set_bool.md) — Toggle a boolean parameter.
- [set_measurement_buf](set_measurement_buf.md) — Live-update the edit buffer for a measurement parameter row.
- [set_number_buf](set_number_buf.md) — Live-update the edit buffer for a numeric parameter row.
- [set_text](set_text.md) — Set a text parameter's value directly. Ignores an empty name.
