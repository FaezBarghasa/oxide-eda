# supply

## Functions

- [add_alternate](add_alternate.md) — Append a new, approved alternate part draft.
- [add_listing](add_listing.md) — Append a new, empty distributor listing.
- [remove_alternate](remove_alternate.md) — Remove alternate `idx` when it is in range.
- [remove_listing](remove_listing.md) — Remove listing `idx` when it is in range.
- [set_alternate_manufacturer](set_alternate_manufacturer.md) — Set alternate `idx`'s manufacturer name.
- [set_alternate_mpn](set_alternate_mpn.md) — Set alternate `idx`'s manufacturer part number.
- [set_alternate_notes](set_alternate_notes.md) — Set alternate `idx`'s free-text notes, storing `None` when blank.
- [set_alternate_status](set_alternate_status.md) — Set alternate `idx`'s lifecycle status.
- [set_listing_distributor](set_listing_distributor.md) — Set listing `idx`'s distributor from a picked source.
- [set_listing_sku](set_listing_sku.md) — Set listing `idx`'s distributor SKU.
- [set_listing_url](set_listing_url.md) — Set listing `idx`'s product URL, storing `None` when blank.
- [set_primary_manufacturer](set_primary_manufacturer.md) — Set the primary part's manufacturer name.
- [set_primary_mpn](set_primary_mpn.md) — Set the primary part's manufacturer part number.
- [set_primary_notes](set_primary_notes.md) — Set the primary part's free-text notes, storing `None` when blank.
- [set_primary_status](set_primary_status.md) — Set the primary part's lifecycle status.
