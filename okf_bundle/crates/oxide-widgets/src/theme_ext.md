# theme_ext

Theme bridge layer — converts `oxide_types::theme::ThemeTokens` to Iced styles.

## Docstring

Theme bridge layer — converts `oxide_types::theme::ThemeTokens` to Iced styles.

All colors in the widget crate flow through this module so that
no hardcoded color values leak into widget code.
